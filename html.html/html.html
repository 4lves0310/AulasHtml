Arquitetura Cliente servidor da WEB

As tecnologias fundamentais que compõem a WEB são:

  • Arquitetura Cliente Servidor
  • HTTP - Hyper Text Transfer Protocol
  • HTML - Hyper Text Markup Language
  • Navegador Cliente
  • Servidor web

Ao longo dos anos foram a web evoluiu e nova tecnologias foram incorporadas como CSS e JavaScript
